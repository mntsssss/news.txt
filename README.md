# NEWS.TXT — минималистичный новостной агрегатор

## Описание
Черно-белый минималистичный новостной сайт. Позволяет искать новости по ключевым словам и сохранять понравившиеся статьи в избранное.

## Функционал
- Поиск новостей через NewsAPI
- Сохранение статей в избранное 
- Удаление из избранного
- Адаптивный дизайн
- Минималистичный черно-белый интерфейс

## СТЕК
- Backend: Node.js, Express
- API: NewsAPI
- Frontend: HTML, CSS, JavaScript
- Хранение: localStorage
