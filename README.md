# NEWS.TXT — минималистичный новостной агрегатор

## Описание
Черно-белый минималистичный новостной сайт. Позволяет искать новости по ключевым словам и сохранять понравившиеся статьи в избранное. Данные хранятся в `localStorage`, поэтому избранное не пропадает после перезагрузки страницы.

## Функционал
- Поиск новостей через NewsAPI
- Сохранение статей в избранное 
- Удаление из избранного
- Адаптивный дизайн
- Минималистичный черно-белый интерфейс

## СТЕК
- Backend: Node.js, Express
- API: NewsAPI
- Frontend: HTML, CSS, JavaScript
- Хранение: localStorage

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ВАШ_НИК/my-news-app.git
cd my-news-app
```

2. Установите зависимости:
Проект использует следующие библиотеки:

express — серверный фреймворк

axios — для HTTP-запросов к NewsAPI

dotenv — для работы с переменными окружения

nodemon — для автоматического перезапуска сервера при изменениях (только для разработки)

Установите их одной командой:

```bash
npm install
```

3. Настройте переменные окружения
Создайте файл .env в корне проекта и добавьте ваш API-ключ:

```text
NEWS_API_KEY=ваш_реальный_ключ_от_newsapi
PORT=3000
```
Как получить API-ключ:
Зарегистрируйтесь на newsapi.org
Подтвердите email
Скопируйте ключ и вставьте в файл .env

4. Запустите проект
Для разработки (с автоматической перезагрузкой):

```bash
npm run dev
```
Для обычного запуска:

```bash
npm start
```

5. Откройте сайт
Перейдите в браузере по адресу:

```text
http://localhost:3000
```

Как это работает
1) Пользователь вводит поисковый запрос в поле на сайте
2) JavaScript на фронтенде отправляет запрос на сервер: /api/news?q=запрос
3) Сервер (Express) получает запрос, контроллер вызывает сервис
4) Сервис обращается к NewsAPI с вашим ключом и получает новости
5) Новости возвращаются на фронтенд и отображаются в виде карточек
6) При нажатии «Сохранить» статья добавляется в localStorage
7) На вкладке «Избранное» отображаются все сохранённые статьи
